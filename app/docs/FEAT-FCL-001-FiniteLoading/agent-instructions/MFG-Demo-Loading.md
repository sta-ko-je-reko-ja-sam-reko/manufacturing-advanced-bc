You load sample data for the Finite Loading feature of Manufacturing Advanced in Business Central.

Tool: `demoLoadingSet`, bound action `importDemoData`.

It calculates the finite load plan of the first work center that has open operations on firm planned or released
orders, and builds the configuration package MFG-LOADING. It changes no production order.

It does not enable the feature. That is done in the Manufacturing Advanced guided setup. Run the action only when a
person asks for sample data, and tell them which company it went into.

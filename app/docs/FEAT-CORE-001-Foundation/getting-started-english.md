# FEAT-CORE-001 - Foundation

## Overview

Manufacturing Advanced is a set of features you switch on one at a time. The guided setup walks you
through them in order: for each one you choose whether to enable it, whether to create the numbering it
needs, and whether to load sample data so you can try it out first. A feature you leave off changes
nothing in your company.

## Setup

### Open the guided setup

1. Search for **Manufacturing advanced guided setup**, or open **Assisted Setup** and choose
   **Set up Manufacturing Advanced**.
2. The list shows **Foundation** first, then one line per feature, each with its status.

### Set up a feature

1. Select a line and choose **Set up**, or choose its name.
2. Read the introduction and choose **Next**.
3. Choose what to set up:
   - **Enable this feature** switches the feature on.
   - **Create and assign number series** creates the numbering the feature uses, if it has any.
   - **Load sample data** creates example records for the feature in this company, together with a
     configuration package for the feature that you can review and export to other companies. It is safe
     to run more than once.
4. Choose **Next**, then **Finish**. You return to the list, where the line now shows **Completed** if you
   enabled the feature.

### Finish

Close the list when you are done. If you enabled or disabled any feature, a message counts down and your
session restarts, so that the pages and actions of the features you switched on appear. You only restart
once, however many features you changed.

## Usage

### Open a feature's full settings

On the guided setup list, select the feature and choose **Detailed setup** to open all of its settings,
including the ones the guided steps do not cover.

## Notes

- The **Manufacturing advanced setup** page has nothing to fill in. Each feature keeps its own settings.
- Sample data is example data for trying a feature out. Review it before relying on it in a company you
  use for real work.
